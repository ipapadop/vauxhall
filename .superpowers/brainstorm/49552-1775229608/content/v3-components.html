Component Structure

Modular design for scalability

Package Layout
  • 📁 vauxhall/
    • 📁 dashboard/
      • 📄 app.py (Main entry)
      • 📄 ui_components.py (Agent cards)
      • 📄 mqtt_client.py (Subscriber logic)
    • 📁 hooks/
      • 📄 client.py (Common publisher library)
      • 📁 gemini/
        • 📄 pre_command.py
        • 📄 post_command.py

Key Benefits

  • Isolation: Dashboard UI is decoupled from the network layer.
  • Reusability: The same client.py can be used for Claude or Codex hooks later.
  • Stability: MQTT thread prevents the GUI from freezing during network hiccups.
