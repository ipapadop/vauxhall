Error Handling & Resilience

Ensuring agent performance and UI reliability

Resilience Scenarios
Scenario: Broker is Offline

Hooks: Timeout after 200ms, exit quietly. Agent continues working unaffected.
Dashboard: Show "Disconnected" status, retry every 5 seconds.

Scenario: Agent Crashes or Exits

Dashboard: "Stale" timer starts. After 2 minutes of silence, the agent card is grayed out.

Scenario: High Network Latency

MQTT Thread: Messages are processed in the background, keeping the Tkinter UI responsive at 60fps.
